Drop photographs here.

Upload the full-size originals straight from the camera -- do not resize them
first, and do not worry about the file name or the extension. They are resized
automatically, added to the gallery, and this folder empties itself. Allow two
to three minutes, then reload the website.

New photographs appear at the end of the gallery. To move them earlier, edit
order.txt in the main folder.

Check the Actions tab to see whether it worked: a green tick means done. If
something could not be read it stays here and a file called UNREADABLE.txt
appears explaining why.
